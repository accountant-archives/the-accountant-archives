# The Accountant Archives — Build Roadmap

This roadmap keeps the archive stable while it grows. Existing stories, drafts, votes, and accounts are preserved; changes are additive and protected by migrations.

## Now — archive clarity and writing flow

- [x] Show canon titles as the film’s main title, with the official prompt title retained as a smaller record label.
- [x] Give writers the previous canon hand-off note before they start a film; make the hand-off required for new submissions.
- [x] Make canon and active challenges unmistakable across the archive, with filters for canon, challenged, and unwritten films plus a newest-canon view.
- [x] Complete vote, bookmark, comment, and canon-battle feedback without page reloads.
- [x] Keep discussion open by default and direct challenge votes through the dedicated canon ballot.
- [x] Rename the visible “ledger” to **sparkle points**.
- [x] Add an in-app expanded writing mode for long sessions.

## Next — facts and moderation

- [x] Add a hierarchical, source-first Fact Sheet with nested entries, selectable story passages, extra citations, and community support/dispute reactions.
- [x] Let any signed-in member publish a sourced fact directly; the community, not an approval queue, keeps the record honest.
- [~] Add a complete reporting flow: stories can now be reported and moderators can claim, dismiss, or hide reported stories and comments. Restoration and fan-art reports are next.
- Add mod assignment, supermod oversight, safe point floors, role thresholds, and auditable point adjustments.

## Community layer

- [~] Public author profiles with bio, published stories, and rank trims. Profiles can now be opened from story and comment bylines; their owners can edit a name and bio. Fan art, achievements, and leaderboards are next.
- Notifications for reactions, comments, challenges, edit proposals, and moderation work.
- Achievements, badges, and a careful point economy with an additional spendable pencil-shaving currency.
- Cute, customisable Grothkin avatars and unlockable cosmetics.

## Fan art and personalisation

- Fan-art gallery with captions, optional movie links, reactions, comments, reporting, and moderator removal.
- Add an image-safety review step before any uploaded media becomes public.
- Allow point-gated reader customisation for theme, background, and type settings.

## Advanced collaboration

- Upgrade story-edit proposals with before/after comparison, change highlighting, weighted moderator votes, thresholds, and automatic expiry.
- Revision and continuity tooling that makes contradictory facts easy to find and resolve.

## Deployment

- GitHub remains the source of truth.
- Vercel will be linked to the `main` branch for automatic production deploys and preview URLs for future branches.
- GitHub Pages can remain live during the transition, then redirect once the Vercel domain is confirmed.
